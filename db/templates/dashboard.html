About TPMS

TPMS (Tizen Performance Monitoring System)

Tizen 타겟 디바이스의 성능을 자동으로 측정하고 모니터링하는 시스템입니다. 다양한 Tizen 프로파일과 버전에 걸쳐 핵심 성능 지표를 측정하여, 성능 회귀(regression)와 개선사항을 추적할 수 있습니다.

시스템 아키텍처

🔄 Jenkins CI 새 Tizen 빌드 생성 시 자동으로 테스트 트리거
→
⚡ TPMS Standalone 타겟 디바이스에 이미지 플래싱 후 성능 테스트 실행
→
💾 SQLite DB 측정 결과를 저장하여 추세 분석 지원
→
📊 Web Dashboard 결과 시각화 및 빌드 간 비교 기능 제공

측정 항목

Booting Time시스템 부팅 소요 시간
Memory Usage시스템 및 프로세스 메모리 사용량
App Launching애플리케이션 실행 시간
Web App Launching웹 애플리케이션 실행 시간
DALI 3D UI3D UI 렌더링 성능
OctaneJavaScript 엔진 벤치마크
NAND Usage저장공간 사용량
Dependency Info라이브러리 의존성 분석

워크플로우

  1. Jenkins CI에서 새 Tizen 빌드가 생성되면 TPMS 테스트 잡을 트리거합니다
  2. TPMS가 타겟 디바이스에 새 이미지를 플래싱하고 설정된 성능 테스트를 실행합니다
  3. 테스트 결과를 파싱하여 SQLite 데이터베이스에 저장합니다
  4. 이 대시보드에서 결과를 시각화하고, 추세를 확인하며 빌드 간 비교를 할 수 있습니다

지원 프로파일

TPMS는 unified-rpi (32bit/64bit), mobile, wearable, toolchain 등 다양한 Tizen 프로파일을 지원합니다. 새로운 프로파일은 설정 파일을 통해 추가할 수 있습니다.
